            JSX: JavaScript XML

            JSX or JavaScript XML is not writing HTML inside javascript. JSX is HTML like syntax
            It is javascript XML like html syntax but not html.

            parcel is doing job to execute the jsx code / to run jsx code
            babel is javascript compiler - babel transpiles to convert one code into another
            attributes must be camelcase in jsx: <h1 className="top"></h1>
            if you write JSX in multiple lines use round brackets for writing in multiple lines
